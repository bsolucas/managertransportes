    Aviso por e-mail

    Quando um cliente pedir uma corrida, enviamos um e-mail para este endereço, mesmo com o app fechado.

    O aviso caiu no spam? Faça isto uma vez
    1. Abra o e-mail na pasta Spam e clique em Não é spam.
    2. Para nunca mais cair lá: com o e-mail aberto, toque nos três pontinhos (⋮) → Filtrar mensagens como essa → Criar filtro → marque Nunca enviar para spam → Criar filtro.
    3. Se ele for para a aba Promoções, arraste para Principal e responda Sim para valer nas próximas.
    4. O assunto sempre começa com "Nova corrida #", o que ajuda a criar o filtro. Se usar Outlook ou outro e-mail, o caminho é parecido: marque como "não é lixo eletrônico" e adicione o remetente aos contatos.
